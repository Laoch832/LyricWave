## 5. Vercel 部署准备情况

本地已确认从 website/ 可构建。部署设置为：

- Framework：Next.js；Node.js：24。
- Root Directory：website。
- 启用 **Include source files outside of the Root Directory in the Build Step**，因为内容同步需要上级 README、docs、许可与 profile 文件。
- 安装命令：npm ci；构建命令：npm run build；输出目录使用框架默认值。
- NEXT_PUBLIC_SITE_URL：实际公开 HTTPS origin，不含路径；缺省可使用 Vercel 生产域名变量，最后才回退本地地址。无效配置会明确失败。
- GITHUB_TOKEN：可选、仅服务器使用的读取凭据，不需要发布权限，不使用 NEXT_PUBLIC_ 前缀。

完整命令及维护流程见 README.md。没有实际验证远端 Vercel 项目设置或线上部署，也没有为此修改任何远端资源。

## 6. 已修复的问题

1. 摘录文章的相对链接未转换，架构页的文档目录链接会进入不存在的路由。
2. 英文介绍的简体中文链接被统一语言替换规则改写为指向自身；英文源码构建页的来源引用也已纠正。
3. README 保存时机描述与当前源码不一致，且中文摘要未明确当前选中歌词来源。
4. 缺少 ESLint、仅内部绝对路径链接检查，以及新增未映射文档会静默遗漏的问题。
5. 初始 TypeScript 版本超出 lint 解析器支持范围；改为兼容的 TypeScript 6.0.3、ESLint 10、官方 Next 和 Hooks 插件组合。对开发工具的现代 minimatch 消费者定向固定已修复版本，避免旧版 globparts 放大问题；移除未使用的 @orama/orama 直接依赖。
6. 无效 Release URL 可能使验证回调抛错；强化 URL 来源、路径、凭据和端口限制，并区分无效 JSON 与网络失败。
7. 英文社交描述继承、标题重复与 origin 规范化问题；统一元信息、语言、规范链接和安全响应头。
8. 文档 GIF 绕过按需播放；改用同一可暂停、离屏停止的播放组件。
9. 英文来源的语言误判及正文语言标记缺失。
10. 小附件统一以 MB 显示造成“0.0 MB”；改为实际 B / KiB / MiB。
11. 首页 TTML 概念片段缺少词结束时间；补全属性、支持键盘滚动，并修复 375px 下由完整片段暴露的横向溢出。
