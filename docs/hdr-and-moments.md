# HDR 歌词与朋友圈链接分享

## HDR 歌词

入口：**澜音模块设置 → 歌词效果 → HDR 歌词显示**。开启后强制停止并重开 Apple Music。

- 亮度比例为 **100%–800%**，默认 200%。这是相对 SDR 的目标亮度，不是面板实测尼特值。
- **震爆弹模式**一键开启 HDR 功能、请求最高窗口亮度和系统可用 HDR 余量。实际输出仍由屏幕、自动亮度、节电与温控策略决定，不能保证强制触发厂商 HBM。
- 只有歌词页面可见且持有窗口焦点时接管亮度；暂停页面、切后台、打开其他窗口或关闭功能后恢复此前窗口设置。
- 真正的 HDR 字形需要 Android 14+、HDR 屏幕及硬件加速。旧设备保留普通歌词；震爆弹只能请求普通最高窗口亮度。

实现使用 Android `Gainmap` 为原生字形绘制添加相对亮度元数据，保留原文布局、声部和外层模糊。绘制限定在已验证歌词 RecyclerView 中的文字，复用有内存上限的位图。需要 GPU Canvas 的不兼容字形回退原生绘制。不会改系统全局亮度设置。

## 朋友圈：网易云音乐跳板，保留可点击链接

**禁止 Hook 微信。** 此版本完全移除微信桥接模块，入口同时拒绝微信主进程和子进程，即使 LSPosed 仍保留旧版作用域选择也不会在那里安装 Hook。

分享路径为 **Apple Music → 澜音确认链接 → 网易云原生分享面板 → 朋友圈**。采用网易云网页资源类型，不替换成网易云歌曲，不生成图片或二维码替代链接，不伪造开放平台身份，也不自动选择目标或发布。

### 开启与使用

1. 覆盖安装新版，在 LSPosed **取消微信**，只为本功能勾选 **Apple Music** 和 **网易云音乐**。
2. 若之前加载过旧版微信桥接，强制停止并重开微信一次以移除旧进程中的代码。新版本不会注入微信。
3. 强制停止并重开 Apple Music 和网易云音乐。在澜音 **界面与底栏 → 微信朋友圈分享** 开启入口。
4. 从 Apple Music 分享歌曲链接；如先出现内置目标列表，选择 **更多/其他** 进入系统分享面板。
5. 选择 **分享到朋友圈（歌曲链接）**，核对 URL 后点击 **打开网易云分享面板**，再由用户选择朋友圈并确认发布。

只有含有效 `https://music.apple.com/…` 的分享才添加入口，保留地区、路径和查询参数。图片分享不会冒充链接分享。分享来源可能显示网易云音乐，因为使用的是其本来的分享流程；链接目标仍为 Apple Music，并非微信内直接播放完整歌曲。

### 验证边界

自动化覆盖原生模型构造、URL 保留、网页资源类型、原生 helper 调用、拒绝邻近未知版本及非 Apple 链接，以及 HDR 元数据、位图复用和亮度恢复。

真实屏幕 HDR 输出与网易云到微信的最终卡片展示仍需真机验证。版本、原签名或成员不匹配时明确提示，不能退回图片，也不能改用微信 Hook。
